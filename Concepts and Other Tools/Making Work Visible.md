- **Making Work Visible**: Showing all team work in one visible workflow so the team can understand flow, priorities, blockers, and capacity.

## Why it matters

Work that is not visible cannot be managed effectively. A visible workflow helps teams see delays, blocked work, overloaded people, competing priorities, and unplanned work.

## Kanban board

A Kanban board is a common way to make work visible. It can be a physical board or a digital tool such as Jira or Trello.

Typical columns are:

- To do
- In progress
- Review or testing
- Done

## What to track

Teams can categorize work in a way that fits their context. Common categories are:

- Features
- Operational work
- Technical debt
- Compliance and risk work
- Unplanned work

## How to use the data

Review the workflow regularly. Look for blocked work, slow-moving work, too much work in progress, and workload imbalance.

Use the data to set priorities, reserve capacity, improve forecasts, and discuss trade-offs with stakeholders.

## Key idea

The purpose of making work visible is not reporting or controlling teams. It is to reduce burden, expose problems, and improve flow.
